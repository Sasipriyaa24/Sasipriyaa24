## 🛡️ RiskLens-AI

An AI-powered transaction risk investigation assistant designed to help analyze banking transaction data and identify unusual activity.

**Tech Stack:** Python, AI/ML, Data Processing, CSV Analysis, Web Technologies

**Features:**

* 📂 CSV transaction upload
* 🔍 Transaction pattern analysis
* ⚠️ Large transaction detection
* 🕐 Odd-hour activity detection
* 👤 New-payee transaction analysis
* 📊 Traceable risk insights
* 📋 Investigation-oriented reports

The system highlights transactions that may require attention without automatically claiming that a transaction is fraudulent.
